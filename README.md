# Моя школа — образовательная платформа для школьников 1–11 классов (сайт + приложение)

Задания по всем школьным предметам, игры, уровни и значки. Ученик занимается сам, учитель ведёт класс и выдаёт домашние задания, родитель следит за прогрессом и включает безлимит. Сайт и мобильное приложение работают от **одного бэкенда и одного аккаунта**, клиент написан **один раз** (Expo / React Native) и собирается под веб, iOS и Android. Сайт устанавливается на телефон как приложение (PWA) и может собираться в APK.

## Что внутри

```
backend/               NestJS + PostgreSQL: API, роли, классы, задания, игры, рейтинг, подписка
backend/src/content/   Банк заданий: 11 предметов, 1–11 классы (проверяется командой ./scripts/check-content.sh)
app/                   Expo (React Native): лендинг, кабинеты ученика/учителя/родителя, игры
app/public/            Манифест PWA, service worker, значки; сюда же кладётся APK (public/downloads/)
scripts/               check-content.sh (проверка заданий), backup.sh (бэкап БД), check-domain.sh (диагностика домена)
.github/workflows/     Сборка Android APK (запуск вручную)
```

### Предметы
Математика 1–11, русский язык 1–11, литература 5–11, английский 2–11, окружающий мир 1–4, биология 5–11, география 5–11, физика 7–11, химия 8–11, история 5–11, информатика 5–11. Типы заданий: выбор, «верно/неверно», ввод числа/слова, расстановка по порядку, соединение пар. Игры: «Молния» (60 секунд) и «Найди пару».

### Как добавлять и править задания
Задания — обычные файлы TypeScript в `backend/src/content/` (по одному на предмет). Математика и информатика частично генерируются кодом с независимой проверкой ответов. После правки запустите `./scripts/check-content.sh` — он проверит ответы, варианты, дубли и выведет статистику. При следующем запуске бэкенд сам синхронизирует банк с базой: изменённые темы обновятся, прогресс по неизменённым сохранится.

### Обновление сайта на сервере
```bash
cd ~/Ybabushki && ./deploy.sh
```

### Резервные копии
`./scripts/backup.sh` сохраняет базу в `~/backups` (последние 14 копий). Для ежедневного запуска добавьте строку в `crontab -e` (она написана в начале скрипта).

### Приложение для Android
Установка без магазинов: откройте сайт в Chrome на телефоне → «Установить приложение». Либо соберите APK: на GitHub вкладка **Actions → «Сборка Android APK» → Run workflow**; готовый файл появится в **Releases** (`apk-latest`). Положите его на сервер в `app/public/downloads/moya-shkola.apk` — на сайте появится кнопка «Скачать APK». iPhone: Safari → «Поделиться» → «На экран “Домой”».

## Запуск на сервере (Docker)

Нужен сервер с Linux (VPS) и установленными Docker и Docker Compose.

```bash
git clone https://github.com/Ptaha100-tech/Ybabushki.git
cd Ybabushki
cp .env.example .env
nano .env            # задайте POSTGRES_PASSWORD, JWT_SECRET (openssl rand -hex 32) и DOMAIN
docker compose up -d --build
```

Сайт откроется по адресу `https://ваш-домен` (см. раздел про HTTPS ниже). Проверка API: `https://ваш-домен/api/health` → `{"status":"ok"}`.

Обновление после новых коммитов: `./deploy.sh`.

Логи: `docker compose logs -f backend`.

### HTTPS и домен

1. Создайте у регистратора DNS-запись типа `A` для `@` с IP вашего сервера.
2. В файле `.env` задайте `DOMAIN=ваш-домен.ru` (без `http://`).
3. Запустите `docker compose up -d --build`. Сервис Caddy сам получит сертификат и будет его продлевать.

Порты 80 и 443 на сервере должны быть открыты.

## Мобильное приложение

Веб-версия собирается автоматически в Docker. Для телефонов:

```bash
cd app
npm install
npx expo install --fix                      # выравнивает версии пакетов под Expo SDK
EXPO_PUBLIC_API_URL=https://ваш-домен.ru/api npx expo start
```

Для быстрой проверки откройте QR-код в приложении Expo Go. Сборки для магазинов (App Store, Google Play, RuStore) делаются через [EAS Build](https://docs.expo.dev/build/introduction/): `npx eas build`. Перед этим замените `bundleIdentifier`/`package` в `app/app.json`. Адрес `EXPO_PUBLIC_API_URL` для мобильных сборок должен быть полным (с доменом), потому что у приложения нет «своего» домена.

## Локальная разработка

```bash
# база данных
docker compose up -d db
# бэкенд
cd backend && npm install
DATABASE_URL=postgres://uchi:ВАШ_ПАРОЛЬ@localhost:5432/uchi JWT_SECRET=dev npm run start:dev
```

В `docker-compose.yml` у `db` нет проброса порта наружу; для локальной работы добавьте `ports: ["5432:5432"]` в сервис `db`.

## Быстрая проверка работы

1. Зарегистрируйтесь как **учитель**, создайте класс, запомните код.
2. В другом браузере зарегистрируйтесь как **ученик**, вступите в класс по коду, решите несколько заданий.
3. Зарегистрируйтесь как **родитель**, добавьте ребёнка по коду из профиля ученика.
4. Учитель выдаёт домашнее задание, ученик выполняет его без лимита.

## Важно знать перед настоящим запуском

Этот код написан без возможности запустить сборку и тесты в среде разработки, поэтому при первом запуске возможны небольшие правки (версии пакетов Expo, мелкие ошибки типов). Чего ещё не хватает до продакшена:

- **Оплата.** Сейчас `PAYMENTS_MODE=mock` включает безлимит без денег — только для проверки. Нужен платёжный провайдер (например, ЮKassa) с подтверждением платежа через webhook. Для сборок в App Store и Google Play действуют правила магазинов об оплате внутри приложения.
- **Миграции БД.** Схема создаётся автоматически (`DB_SYNC=true`). Перед запуском для реальных пользователей перейдите на миграции TypeORM и поставьте `DB_SYNC=false`.
- **Защита.** Добавьте ограничение частоты запросов (например, `@nestjs/throttler`), подтверждение e-mail и восстановление пароля.
- **Данные детей.** Ученики регистрируются по e-mail без согласия родителей. Для детей лучше создавать аккаунты через учителя или родителя. Проверьте требования законодательства о персональных данных вашей страны (в России — 152-ФЗ, в том числе хранение данных граждан РФ на серверах в РФ) и согласуйте политику конфиденциальности с юристом.
- **Контент.** Задания написаны автоматизированно и проверены скриптом, но не методистом; перед широким запуском попросите учителей просмотреть их. Не копируйте задания, персонажей и оформление Учи.ру: они защищены авторским правом. Нужны свои методисты, редактор заданий и новые типы заданий (перетаскивание, сортировка и т. д.).
- **Не сделано:** олимпиады, push-уведомления, подтверждение e-mail и восстановление пароля.
